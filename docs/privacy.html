データの取り扱い

プライバシーポリシー

このポリシーは、iPhone アプリ「Pinto」に適用されます。

データの収集と利用

Pinto はアカウント登録を必要としません。開発者はアプリを通じて個人情報や利用状況を収集しません。Pinto は広告配信、アクセス解析、トラッキングを行いません。

選択・撮影した画像、入力した課題名やタグ、ホールドやルートなどの編集内容は、課題の作成・再編集のために端末内のアプリ領域に保存されます。ホールドの輪郭検出も端末上で行い、Pinto はこれらのデータを開発者のサーバーや外部サービスへ自動送信しません。

写真の保存と共有

カメラは、課題用の写真を撮る操作を選んだときに使います。完成した画像を写真ライブラリに追加する際は、iOS が求める許可が必要です。画像を共有する場合は、iOS の共有画面から利用者が共有先を選びます。共有先での取り扱いは、そのサービスのプライバシーポリシーをご確認ください。

保存期間と削除

課題と編集データは、課題一覧から該当の課題を削除するか、アプリ自体を削除するまで、端末内のアプリ領域に残ります。写真ライブラリに保存した画像や共有先に渡した画像は、アプリ内で課題を削除しても消えません。必要に応じて保存先・共有先で削除してください。端末のバックアップは iOS の設定に従います。

カメラや写真へのアクセス許可は、iPhone の「設定」から変更できます。

お問い合わせ

このポリシーに関する質問は Pinto サポートに記載の窓口をご利用ください。GitHub Issues への投稿は公開されます。個人情報や非公開の写真は投稿しないでください。このサイトや問い合わせ先の運営に関する情報は GitHub のプライバシーステートメントをご確認ください。

Pinto サポート

Pinto は、壁の写真にホールドや登る順番を書き込み、ボルダリングの課題を作成・共有できる iPhone アプリです。

使い方

アプリ内では、課題一覧の右上にある「？」からユーザーマニュアルをオフラインで読めます。ウェブでも Pinto ユーザーマニュアルをご覧いただけます。

よくある質問

カメラで撮影できない、または画像を保存できない
iPhone の「設定」で Pinto のカメラや写真へのアクセス許可を確認してください。
課題を仲間に送りたい
編集画面上部の共有ボタンから、課題を画像としてメッセージや AirDrop などで送れます。
保存した画像から課題を再編集できますか？
写真ライブラリに保存した画像には編集データが含まれません。再編集するには Pinto の課題一覧から元の課題を開いてください。

お問い合わせ

不具合の報告、使い方の質問、機能のご要望は Pinto の GitHub Issues へお寄せください。投稿には GitHub アカウントが必要です。

不具合の報告には、Pinto と iOS のバージョン、何をしたときに何が起きたかを添えてください。投稿は公開されるため、個人情報や公開したくない写真は添付しないでください。

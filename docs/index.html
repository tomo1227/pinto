Pinto サポート

壁の写真から、オリジナルのボルダリング課題を。Pinto は、ホールドや登る順番を書き込んで、課題を作成・共有できる iPhone アプリです。

使い方

アプリ内では、課題一覧の右上にある「？」からユーザーマニュアルをオフラインで読めます。

お問い合わせ

使い方の質問、不具合の報告、機能のご要望は Pinto の Discord サーバー または Pinto の GitHub Issues へ。投稿にはそれぞれのサービスのアカウントが必要です。

不具合の報告には、Pinto と iOS のバージョン、何をしたときに何が起きたかを添えてください。投稿はほかの利用者にも見えるため、個人情報や非公開の写真は添付しないでください。

よくある質問

カメラで撮影できない、または画像を保存できない

iPhone の「設定」で Pinto のカメラや写真へのアクセス許可を確認してください。

課題を仲間に送りたい

編集画面上部の共有ボタンから、課題を画像としてメッセージや AirDrop などで送れます。

保存した画像から課題を再編集できますか？

写真ライブラリに保存した画像には編集データが含まれません。再編集するには Pinto の課題一覧から元の課題を開いてください。
